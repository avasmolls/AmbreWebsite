# AMBRÉ | Luxury Fragrance Website

**An independently designed and developed fragrance e-commerce concept combining front-end development, UX/UI design, and digital brand identity.**

*Leave a lasting impression.*

## Project Overview

AMBRÉ is a fictional luxury fragrance brand centered around warm, sophisticated, and timeless scents. This independent project was created to strengthen my web development skills while exploring the intersection of user experience design, brand strategy, and e-commerce.

I developed AMBRÉ from the perspective of both a designer and developer, beginning with a brand concept and visual mockups before translating those designs into a functional, interactive website.

My goal was to create a cohesive digital shopping experience that reflects the elegance of a luxury fragrance company while maintaining intuitive navigation, product discoverability, and an engaging user interface.

**Project Type:** Independent Personal Project  
**Status:** In Development  
**Role:** UX/UI Designer, Front-End Developer, Brand Designer

## Key Features

### 1. Luxury Brand Identity & Homepage

Designed a visually engaging homepage that introduces AMBRÉ's brand identity and showcases its signature fragrance collection.

- Editorial-style hero section and product photography
- Warm neutral color palette inspired by amber and natural stone
- Elegant typography and consistent visual hierarchy
- Featured fragrance cards displaying product details
- Responsive navigation and prominent calls to action

### 2. Interactive Fragrance Shop

Developed a dedicated shopping interface where users can explore the fragrance collection.

- Product cards displaying fragrance names, prices, sizes, and scent notes
- Category filtering by scent family: Warm, Dark, Floral, and Fresh
- Responsive product grid
- Interactive shopping interface elements
- Consistent product presentation across the website

### 3. Personalized Scent Discovery Quiz

Created an interactive five-question quiz designed to help users discover fragrances matching their personal preferences.

- Multiple-choice questions based on scent preferences and lifestyle
- JavaScript-based scoring and recommendation logic
- Dynamic fragrance recommendations
- Progress tracking and navigation between questions
- Personalized results featuring product descriptions and fragrance notes
- Ability to retake the quiz or explore recommended products

This feature emphasizes personalization and user engagement within an e-commerce environment.

### 4. Live Fragrance Search

Implemented interactive search functionality using JavaScript and jQuery.

- Live search results as users type
- Search matching fragrance names, scent notes, and descriptions
- Keyword highlighting within results
- Search overlay integrated into the navigation
- Keyboard navigation and accessibility-related controls
- Links from search results to the fragrance shop

### 5. Curated Fragrance Collections

Designed a collections page that organizes fragrances around moods and occasions.

Collections include:
- **The Signature Collection:** Explore the complete fragrance line
- **Evening:** Rich, warm, and sophisticated fragrances
- **Daytime:** Bright, floral, and fresh fragrances

This approach integrates product organization with brand storytelling and helps users navigate products based on their preferences.

## Design & Development Process

### Concept & Research

I began by developing the identity of a fictional luxury fragrance company. My focus was on creating a premium visual aesthetic while considering how potential customers would interact with and navigate the website.

### UX/UI Design

Before development, I used Figma to create visual references and mockups that established the website's overall direction.

Key considerations included:
- Navigation and information architecture
- Product discoverability
- Typography and visual hierarchy
- Consistent branding across pages
- Responsive layouts
- Interactive product exploration

### Front-End Development

Using HTML, CSS, Bootstrap, and JavaScript, I translated my designs into web pages and developed interactive features.

The project provided opportunities to strengthen my understanding of responsive styling, DOM manipulation, event handling, reusable product data, and user-driven functionality.

### AI-Assisted Development

I also experimented with generative AI throughout the creative and development process.

AI tools supported:
- Exploration of brand imagery and visual concepts
- Creation of mockup references
- Troubleshooting layout and styling issues
- Experimentation with design alternatives

I used these resources as supporting tools while independently directing the project's branding, design decisions, and implementation.

## Getting Started

To explore the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/avasmolls/AmbreWebsite.git
```

**2. Navigate to the project directory**

```bash
cd AmbreWebsite
```

**3. Open the website**

Open `index.html` in a browser or use a local development server such as VS Code Live Server.

The project uses Bootstrap and Google Fonts through external resources, so an internet connection is recommended.
